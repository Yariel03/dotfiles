# 👑 GUÍA DE ATAJOS Y COMANDOS - HYPRLAND
> 💡 **Navegación Nvim:** `j` / `k` (bajar/subir) • `Ctrl+d` / `Ctrl+u` (media página) • `/` (buscar) • `q` o `Esc` (salir)

## 🚀 APLICACIONES
  `SUPER + RETURN`              💻 Abrir terminal Kitty
  `SUPER + E`                   📁 Explorador de archivos Dolphin
  `SUPER + R`                   ⚡ Lanzador de aplicaciones Hyprlauncher
  `SUPER + G`                   ⏺️ Script de grabación de pantalla (grabar.sh)
  `SUPER + V`                   📋 Historial del portapapeles (Neovim TUI)

## 🪟 GESTIÓN DE VENTANAS
  `SUPER + Q`                   ❌ Cerrar ventana activa
  `SUPER + F`                   🔲 Alternar ventana flotante (Toggle Float)
  `SUPER + P`                   📌 Fijar ventana (Pin) en todos los escritorios
  `SUPER + J`                   🔀 Alternar división horizontal/vertical (Dwindle split)
  `SUPER + Flechas`             👀 Mover foco de atención entre ventanas
  `SUPER + SHIFT + Flechas`     🔄 Mover posición física de la ventana
  `SUPER + Clic Izquierdo`      🖱️ Arrastrar y mover ventana flotante con ratón
  `SUPER + Clic Derecho`        📐 Redimensionar tamaño de ventana con ratón

## 📸 CAPTURAS DE PANTALLA
  `SUPER + C`  ó  `PrtSc`       ✂️ Captura de región seleccionada (Hyprshot)
  `SUPER + D`  ó  `SHIFT+PrtSc` 🎨 Capturar región y dibujar/anotar con Swappy
  `SUPER + SHIFT + C`           🪟 Capturar ventana activa (Hyprshot)
  `SUPER + ALT + C`             🖥️ Capturar pantalla completa

## 🖥️  ESPACIOS DE TRABAJO (WORKSPACES)
  `SUPER + 1 .. 9`              🔢 Cambiar al espacio de trabajo 1 al 9
  `SUPER + SHIFT + 1 .. 9`      📦 Mover ventana activa al espacio 1 al 9
  `SUPER + ALT + ← / →`         ↔️ Navegar entre escritorios activos
  `SUPER + S`                   ⭐ Alternar espacio especial (Scratchpad)
  `SUPER + SHIFT + S`           📥 Enviar ventana al espacio especial (Scratchpad)
  `SUPER + Rueda Ratón`         🖱️ Desplazarse entre escritorios de trabajo

## ⚙️  SISTEMA Y CONTROL
  `SUPER + H`                   ⌨️ Ver esta guía de atajos y comandos
  `SUPER + L`                   🔒 Bloquear pantalla (Hyprlock)
  `SUPER + N`                   🔔 Abrir/Cerrar centro de notificaciones (SwayNC)
  `SUPER + M`                   🚪 Salir de Hyprland (Exit session)

## 🎵 MULTIMEDIA Y AUDIO
  `Volumen +/- / Silenciar`     🔊 Subir/bajar volumen y mutear micrófono (SwayOSD)
  `Play / Pause / Next / Prev`  ⏯️ Control de reproducción (YouTube, Spotify, etc.)
